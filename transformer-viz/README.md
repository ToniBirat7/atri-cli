# Transformer Attention Layer Visualization

This is a premium, interactive visualization project created to test the capabilities of **Atri Code v2**.

## Features
- **Dynamic Attention Map**: Real-time calculation of $Attention(Q, K, V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$.
- **Interactive Controls**: Adjust dimensionality ($d_k$) and number of heads.
- **Modern UI**: Glassmorphism aesthetic with high-performance canvas rendering.

## How to use
Simply open `index.html` in your favorite modern browser.

## Project Goal for Atri Code
The next step is for `atri-cli` to implement the "Head Switching" logic and "Vector Lines" overlay to visualize how different heads focus on different parts of the sequence.
